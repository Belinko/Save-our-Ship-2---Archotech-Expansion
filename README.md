# Save-our-Ship-2---Archotech-Expansion
Adds a majority of new archotech ship hardware for sos2 and new faction of enemy ships to fight.

This mod requires Rimworld 1.6
Rimworld Royalty DLC
More Shield Belts: https://steamcommunity.com/workshop/filedetails/?id=3265661340
Save Our Ship 2: https://steamcommunity.com/workshop/filedetails/?id=1909914131
Harmony: https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077

How to install:
-Press CODE - download ZIP
-Open Rimworld game folder
-Unpack the ZIP into Romworld/Mods
-It should show up in the games mod manager
-Enable it and all required mods and relaunch the game.
